# VESPER

<img src="icon.png" alt="VESPER 图标" width="72" height="72">

一个面向 Windows 的极简桌面音乐播放器，支持网易云音乐账号与本地音频。使用 Electron、原生 HTML / CSS / JavaScript 和 Node.js 构建，保留搜索、收藏、歌单和播放功能，没有推荐流与推送。

## 功能

- **搜索与曲库**：歌曲、歌手、专辑分类搜索，支持部分关键词和输入建议；读取自己的网易云歌单、收藏专辑和关注歌手列表。
- **云端收藏同步**：红心歌曲按网易云「我喜欢的音乐」歌单顺序展示；添加 / 取消红心、收藏 / 取消收藏专辑会同步到当前网易云账号。
- **红心专用搜索**：在「同步红心」右侧按歌名、歌手或专辑筛选全部红心歌曲，包括尚未滚动加载的歌曲。
- **连续浏览**：歌曲、专辑、歌手和歌单内容滚动到底部自动加载，无需点击「加载更多」。
- **本地音乐**：导入 MP3、FLAC、WAV、M4A、OGG、AAC、OPUS 文件，管理本地收藏与播放队列。
- **音质选择**：可请求不同音质，并显示接口实际返回的音质；高音质不可用时尝试回退。
- **两种歌词布局**：封面与滚动歌词并排，或大封面配合逐句淡入淡出的歌词；支持翻译歌词与纯音乐提示。
- **封面取色**：歌词播放页根据专辑封面生成背景色，主页使用独立背景图。
- **曲目衔接**：可设置 0、2、4、6、8 秒交叉淡入淡出。
- **整轮随机播放**：当前队列一轮内不重复，播完再洗牌；手动下一首与自动衔接共用顺序，上一首按实际播放历史返回，重启后保留随机进度。
- **Windows 桌面交互**：自定义全局快捷键、任务栏预览播放按钮、系统托盘、窗口拖动与缩放。
- **简洁播放界面**：最大化 / 全屏播放页的上下操作区按边缘触发显示；列表滚动条在滚动时显示，悬停或拖动时保留，隐藏后右侧边缘可缩放窗口。

## 从源码运行

### 环境

- Windows 10 / 11，系统提供 `powershell.exe`，用于保存和读取 Windows 用户绑定的登录凭证。
- Node.js 与 npm。本地验证版本为 Node.js **24.13.1**，可使用 Node.js 24.x。
- Git，用于克隆仓库。

当前仓库提供源码，尚未提供安装包。`runtime/` 和 `node_modules/` 不随仓库上传，需要自行安装运行环境和依赖。

在 PowerShell 中执行：

```powershell
git clone https://github.com/cutnv/VESPER.git
cd VESPER
npm.cmd ci
npm.cmd start
```

安装依赖后，也可以双击项目目录里的 `启动VESPER.cmd`。

项目可放在任意有写入权限的目录，不要求固定为 D 盘。应用内置服务监听 `127.0.0.1:17634`；启动时该端口需要可用。

## 使用

### 登录与收藏

1. 点击左下角账号区域，用手机网易云音乐 App 扫码并确认登录。
2. 首页默认显示红心歌曲。左侧可切换收藏专辑、关注歌手、本地音乐和歌单。
3. 在歌曲行点击红心可同步收藏状态；进入专辑详情后可收藏或取消收藏专辑。

桌面版网易云音乐不是运行依赖。关注歌手页面目前用于查看账号已有的关注列表，不提供关注 / 取消关注操作。

### 播放与界面

- 搜索后选择歌曲播放，或打开歌单使用「播放全部」。加号用于加入播放队列。
- 点击底部封面进入完整播放页，使用返回箭头回到列表。
- 在设置中选择歌词布局、交叉淡入淡出时长和快捷键。
- 列表滚动条默认隐藏；滚轮滚动时出现，鼠标移入后可拖动，离开后约 1.4 秒自动隐藏。
- 关闭窗口默认隐藏到托盘；要完全关闭应用，使用托盘菜单中的「退出」。

### 默认快捷键

| 场景 | 快捷键 | 操作 |
| --- | --- | --- |
| 应用内，未在输入框或弹窗中操作 | `Space` | 播放 / 暂停 |
| 应用内 | `Ctrl + ←` / `Ctrl + →` | 上一首 / 下一首 |
| 应用内 | `F11` | 切换全屏 |
| 播放页 / 全屏 | `Esc` | 返回列表 / 退出全屏 |
| 全局 | `Ctrl + Alt + Space` | 播放 / 暂停 |
| 全局 | `Ctrl + Alt + ←` / `Ctrl + Alt + →` | 上一首 / 下一首 |

全局快捷键可在设置中修改或关闭。组合键被其他软件占用时，应用会提示更换。

### 音质与播放范围

网易云播放使用当前账号实际拥有的权限。会员身份不代表每首歌曲、每个版本或每档音质都可播放；版权、地区、账号权限和接口返回结果均可能影响播放。

音质选项代表请求目标，实际音质以播放结果为准。部分曲目可能仅能试听或暂不可用；交叉淡入淡出也需要下一首能够正常预加载。

## 本地数据

应用设置、登录凭证、播放状态、缓存和导入歌曲保存在项目目录下：

| 目录 | 内容 |
| --- | --- |
| `data/` | 设置、播放队列、本地曲库信息、账号会话与 Electron 用户数据 |
| `cache/` | 应用与 Chromium 缓存 |
| `temp/` | 临时文件 |
| `local-music/` | 复制导入的本地音频及封面 |

网易云登录会话使用 Windows DPAPI 加密，绑定当前 Windows 用户。更换电脑或 Windows 用户后，应重新扫码登录。

这些目录、桌面快捷方式、环境变量文件和测试生成的截图 / 数据均已通过 `.gitignore` 排除，不进入源码仓库。

### 项目误删后恢复

仓库保存播放器源码、图标、主页背景和依赖锁定文件，可按「从源码运行」重新克隆并执行 `npm.cmd ci`、`npm.cmd start`，恢复仓库对应版本的界面和功能；不需要安装网易云音乐电脑版。也可以在 GitHub 下载 ZIP，解压后安装依赖再启动。

重新扫码登录后，网易云账号中的红心歌曲、歌单、收藏专辑和关注歌手会重新读取。登录状态、本地设置、播放队列、随机进度、本地收藏和导入歌曲不会通过 GitHub 恢复。

如需保留这些本地内容，请先从托盘退出应用，将 `data/` 和 `local-music/` 另行备份到项目之外的私人位置，不要上传到公开仓库。恢复时放回原项目路径；本地曲库记录包含绝对路径，更换路径后需要重新导入歌曲。更换电脑或 Windows 用户后重新扫码登录。`node_modules/` 可重新安装，`cache/` 和 `temp/` 会自动生成，快捷方式需要重新创建。

仓库备份的是程序版本，网易云在线服务、账号权限和第三方接口后续变化仍可能影响在线播放。

## 项目结构

```text
electron.cjs             Electron 主进程、窗口、托盘与快捷键
preload.cjs              主进程与页面之间的受限通信接口
server.cjs               本地服务、网易云接口与曲库管理
app.js                   页面交互、播放队列、收藏与歌词
index.html / style.css   界面与样式
resize.js                窗口拖动、缩放与滚动条交互
crossfade.js             双音频交叉淡入淡出
appearance.js            专辑封面取色
search-suggestions.js    搜索输入建议
shortcuts.cjs            快捷键校验与注册
helpers.cjs              凭证加密等辅助逻辑
assets/                  主页背景与任务栏图标
```

## 技术栈

- Electron `44.8.0`
- 原生 HTML / CSS / JavaScript
- Node.js 本地 HTTP 服务
- [`@neteasecloudmusicapienhanced/api`](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced) `4.41.1`

本项目是独立的个人播放器，不是网易云音乐官方客户端。
